# Landing page de arquitetura

Landing page de um estúdio de arquitetura, feita como projeto do curso de Tecnologia da Escola DNC.

**Site:** [teste-arquitetura.netlify.app](https://teste-arquitetura.netlify.app/)

## O que tem

* Secção de entrada com o posicionamento do estúdio ("tradição em projetos de arquitetura")
* Apresentação dos serviços
* Secção de contacto

## Detalhes técnicos

* HTML e CSS puros, sem JavaScript e sem bibliotecas.
* 62 linhas de HTML e 100 de CSS. O exercício era exatamente esse: fazer uma página apresentável com o mínimo.
* Publicado no Netlify.

## Ver localmente

Abrir o `index.html` no browser. Não há dependências nem servidor a correr.

## Nota

Projeto de 2024, de quando estava a aprender HTML e CSS. Fica no perfil como marco inicial.
